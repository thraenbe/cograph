More connections in Shelf, a function hover card, and the F26 blank canvas

Static pictures to decide from. Part A shows three ways to see the real cross-folder calls that Shelf folds into bundles today. Part B shows three versions of a card that appears when you rest the pointer on a function. Part C shows the fix for the blank canvas after "Show only this file" while zoomed in.

The frames use the round-1 Index-tab look. Canvas colours follow your theme, as the webview does. The full plan is in .ai/plans/ux-round4.md on branch termi/s216.

A · Seeing more of the cross-folder connections

Today every call between two folders collapses into one grey bundle between the folder tabs. Individual lines only appear while the pointer is on a node, and they disappear when it leaves.

A0 · Today baseline

One bundle per folder pair, thickness by call count. examples/ is collapsed. You can see that tests call src 37 times, but not which functions.

A1 · Expand a bundle recommended primary

Click a bundle and it opens into its individual calls, and stays open. Click it again, or press Esc, to fold it.

Route
Each line leaves its frame through the same tab port the bundle used, then fans out to its node. The corridor still reads as one connection.
Cap
60 heaviest calls per pair. The rest stay as a thin bundle labelled +N more, which raises the cap to 300 on click.
Collapsed
Calls into a collapsed folder end on its glyph and merge, with a count.
Zoomed out
Below 0.4 zoom the expansion draws as its bundle again and costs nothing.
Saved
Open bundles are saved with the layout.

A2 · Pin connections recommended secondary

Right-click a folder tab, file slot or function and choose Pin connections. Its cross links stay drawn in the highlight colour and the other bundles dim. This is today's hover behaviour, made sticky.

Undo
Pins are listed as chips in the Filters panel, each with ×.
Many
Several pins can be active at once. All pins and expansions share one 600-line limit.
Answers
"What does this file talk to?" A1 answers "what is inside this bundle?"

A3 · Global detail level not recommended

A three-step switch in the Folder panel: Bundles · Strongest · All. Shown so you can compare.

Why not
On a mid-size repo "All" becomes a hairball even at this toy size, and it costs every edge in every frame. "Strongest" hides the reason a line is drawn.
Keep?
It could come back later as a Strongest preset if A1 and A2 turn out to be too manual.

B · Resting on a function

In all three options the hover card is small and read-only. It reuses the existing folder/file card, so there's still only one tooltip layer. Click stays exactly as it is: it opens the editable source popup, and the card hides the moment you press. The card opens after the pointer rests for 450 ms. Moving more than 4 px restarts the wait, so sweeping across a dense slot never flashes cards.

B3 · Explained add-on, needs your OK

The AI explanation is asked for per function, on demand, never in bulk. The Explain ✦ button sits in the click popup, because the hover card can't be clicked. The answer is stored with the annotations and shows in every later hover, marked outdated once the file changes.

Cost
About $0.006 per function (haiku). A bulk run over a 10k-function repo would be about $6.5, three times the default $2 run budget. That's why this round has no bulk run.
Privacy
The function body is sent only when "Annotate: read source" is on. Otherwise the explanation uses signature, docstring and call names.
Extra
Optional: right-click a file slot, then "Explain functions in this file" (one request).

C · F26: "Show only this file" while zoomed in

After the re-pack the file lands at the top left, outside the zoomed view. The automatic re-fit is skipped because you had zoomed, so the canvas looks empty. Fix: re-fit anyway when nothing is left in view. When something is still visible, your zoom stays untouched.

C · Before / after fix in this round

The same check covers Hide folder/file and Global drill-down. The rule is "re-fit when the viewport would show nothing", not "re-fit always".

Decisions for Bela (my default in bold)

  1. More connections: A1 expand-a-bundle as the main way, A2 pin as the second. Or a different pick.
  2. Limits: 60 lines per opened bundle (300 via "+N more"), 600 on screen in total. These get re-checked against the perf benchmark.
  3. Function hover card: B2 Peek (8 lines of code) or B1 Brief (no code)?
  4. AI explanations (B3) this round? Default: yes, on demand from the click popup, cached, no bulk run, body only sent when "read source" is on.
